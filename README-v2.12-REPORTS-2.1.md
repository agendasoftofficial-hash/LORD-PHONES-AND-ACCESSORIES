# G-LOKOO POS v2.12.0 — Reports 2.1

Reports 2.1 expands the management reporting screen with:
- Sales and profit trend
- Payment-method collection meters
- Phone vs accessory sales mix
- Repair status/performance summary
- Returns and refunds by method
- Best sellers
- Expense breakdown meters
- Cashier performance meters
- Inventory alerts
- Business summary
- Existing Print and CSV export

No new database schema is required for this reporting upgrade.
