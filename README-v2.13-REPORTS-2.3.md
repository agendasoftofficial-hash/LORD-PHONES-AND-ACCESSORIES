# G-LOKOO POS v2.14.0 — Reports 2.3

Reports 2.3 adds deeper management reporting on top of Reports 2.2.

## Added
- Detailed sales transaction table now includes item quantity.
- Product Performance Detail table with units, revenue, calculated cost, profit and margin.
- Existing Best Sellers, Cashier Performance, Expense Breakdown, Inventory Alerts, Sales Mix, Repairs and Returns remain available.
- Existing date filters, Print and CSV export remain available.

No new Supabase SQL is required.
