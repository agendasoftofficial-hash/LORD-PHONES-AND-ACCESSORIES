# G-LOKOO POS v2.11.0 — Normal Paper Receipt

Receipt printing updated for normal printers/PDF when no thermal printer is configured.

- Normal-paper receipt uses 100% of the selected paper width.
- Chrome chooses the selected paper size instead of forcing Letter.
- Receipt content is larger and more compact vertically.
- Thermal 58mm/80mm mode remains available when a thermal printer is configured.
- No Supabase changes are required.
