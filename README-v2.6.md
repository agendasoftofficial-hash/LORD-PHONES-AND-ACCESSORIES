# G-LOKOO POS v2.6.0

## Supplier Statements
- View a supplier's complete purchase and payment ledger.
- Shows purchases as debit and supplier payments as credit.
- Shows running supplier balance.
- Displays supplier contact details, invoice numbers, payment methods and references.
- Print Statement opens a clean printable supplier statement.
- Uses the existing `suppliers`, `purchases`, and `supplier_payments` tables; no new SQL migration is required.

## Test
After updating the source, open **Suppliers → Statement** for a supplier with transactions.
